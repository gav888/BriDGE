# Generate Analysis Summary

Creates a comprehensive summary of all analysis results.

## Usage

``` r
bridge_summary(
  discovery_results = NULL,
  mediation_results = NULL,
  comparison_results = NULL,
  sensitivity_results = NULL
)
```

## Arguments

- discovery_results:

  Results from causal discovery

- mediation_results:

  Results from mediation analysis

- comparison_results:

  Results from comparative analysis

- sensitivity_results:

  Results from sensitivity analysis

## Value

A formatted summary object
