# BriDGE: Behavioural research by integrating DAGs and GAMs in Experiments

A comprehensive package for causal analysis of randomized controlled
trial data.

## Details

It features causal discovery, mediation analysis with nonlinear
relationships using GAMs, bootstrapping, sensitivity analysis, and
visualization tools.
